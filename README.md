# Truppen

Ett crowd-runner-spel i webbläsaren: styr en trupp, skjut fiender, välj rätt portar. Nivåer, uppgraderingar, bossar var femte nivå, liv och förmågor som följer med mellan omgångar. Inga annonser, inga köp.

## Spela lokalt

Öppna `index.html` direkt i en webbläsare, eller kör en enkel server:

```
npx serve .
```

## Driftsättning

GitHub Pages publicerar grenen `main` från roten. Varje push till `main` är live efter någon minut på https://dlundin-private.github.io/troops/.
